# Movie Library

## Автор
Инсаф Гатин

## Описание
GUI-приложение для хранения информации о фильмах с фильтрацией по жанру и году, сохранением данных в JSON.

## Функциональность
- Добавление фильмов (название, жанр, год, рейтинг)
- Валидация: год — число, рейтинг — от 0 до 10
- Фильтрация по жанру и году
- Сохранение и загрузка через JSON
- Удаление фильмов

## Установка и запуск
1. Установите Python 3.6+
2. Клонируйте репозиторий
3. Запустите: python3 main.py

## Использование
1. Заполните поля и нажмите «Добавить фильм»
2. Для фильтрации выберите жанр или введите год → «Фильтр»
3. Для сброса фильтров → «Сброс»
